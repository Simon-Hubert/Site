Adrian Engine

Adrian Engine est un moteur de jeu en C++ basé sur les librairies SDL et entt.

Features

Inspecteur

Inspecteur inspiré de celui de Unity

Ajout et Edition de components

Components

De nombreux components usuels inclus de base dans le moteur

Possibilité d'ajouter des components custom

Serialisation

Serialisation de scenes et de components en json. Directement via une macro dans le moteur.

Packaging

Il y a 3 cibles de compilation : le moteur, l'editeur et le jeu. Chacune editable et compilé séparément dans des libs ou des executables

Le code de jeu est donc facilement isolé et maintenable.

J'utilise Xmake pour parametrer facilement les builds et le packaging
